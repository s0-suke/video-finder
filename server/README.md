# Video Finder（サーバー版・旧版）

※ 現在の本体はリポジトリ直下の PWA 版。こちらは Mac 上で Node のサーバーとして動かしていた旧版。

複数の動画サイトから投稿を定期的に収集し、重複をまとめて一覧・検索できるローカル用Webツール。

## 起動

```bash
cd server && npm start
```

起動するとURLが表示されます。スマホは同じWi-Fiにつないで `http://<MacのIP>:8787` を開いてください
（Safariの共有メニュー →「ホーム画面に追加」でアプリのように使えます）。

- Node.js 22.5以上が必要（組み込みの `node:sqlite` を使うため、追加のインストールは不要）
- データは `data.db`（SQLite）に保存されます

## 仕組み

- `collector.js` … 各サイトの WordPress REST API（`/wp-json/wp/v2/posts`）から投稿を取得
  - 起動時と、設定画面で決めた間隔（初期値1時間）ごとに新着だけ取得
  - 初回の全件取得は途中で止めても次回続きから再開
- 重複のまとめ方
  1. タイトルかタグにある品番（例: `MR-KR2387`, `GT-2720`）が同じものは1本にまとめる
  2. 品番がないものは、記号と空白を除いたタイトルが同じなら1本にまとめる
- `server.js` … API と画面の配信（ポート 8787、`PORT` 環境変数で変更可）
- `public/index.html` … 画面（一覧・詳細・絞り込み・設定）

## 制限

- igay69.com は Cloudflare のボット判定で自動取得を拒否されるため、現状は収集できません（設定画面にエラー表示）
- WordPress 以外のサイトは未対応
