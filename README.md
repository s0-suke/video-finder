# Video Finder

複数の動画サイトの投稿を集めて、重複をまとめて一覧・検索できる PWA。
iPhone のブラウザ内だけで収集・保存・検索まで完結し、サーバーは不要。

公開 URL: https://s0-suke.github.io/video-finder/

## 使い方

1. iPhone の Safari で公開 URL を開き、共有メニュー →「ホーム画面に追加」
2. 初回は全件取得に数分〜十数分かかるので、Wi-Fi で開いたままにする（途中で閉じても次回続きから再開）
3. 以降は開くたびに、前回から設定した時間（初期値 30 分）が経っていれば新着だけ取りに行く

## 主な機能

- 画面下のタブバー（ホーム / 新着 / お気に入り / 履歴 / 設定）と検索・絞り込み（片手で操作できる配置）
- 一覧: 検索（全角/半角・品番のハイフンの有無を問わない、最近の検索）、スタジオのチップと名前で探せるスタジオ一覧
- 並び順: 掲載日 / 発売日（目安。otokoki の掲載日）× 新しい順 / 古い順 / ランダム。取得元サイト、サムネイルのない動画を隠す
- 詳細: 広告ブロック付きの再生（非対応の提供元は自動で見分ける）、お気に入り、説明文・出演者などの詳細情報、サンプル画像のカルーセル、同じスタジオの動画、左右スワイプで前後の動画へ
- 設定: 収集対象サイトの追加・削除、自動収集の間隔、お気に入りの書き出し/読み込み、発売日の目安、広告ブロック、追加機能のオン/オフ

## 構成

| パス | 内容 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `js/main.js` | 起動とルーティング |
| `js/data.js` | メモリ上のデータ（統合後の動画・スタジオ）とイベント |
| `js/crawler.js` | 各サイトからの収集（差分・全件・途中再開） |
| `js/source.js` | 投稿本文からプレイヤー・画像・説明文を取り出す |
| `js/matching.js` | 品番の抽出と統合キー（純粋関数） |
| `js/db.js` / `js/wp.js` | IndexedDB / WordPress REST API |
| `js/player.js` | 広告ブロック付きの再生 |
| `js/favorites.js` / `js/history.js` | お気に入り / 視聴履歴 |
| `js/details.js` | 外部サイト（otokoki.net・レーベル公式）の詳細情報とサンプル画像 |
| `js/release.js` | 発売日の目安（otokoki の記事タイトルと日付の対応表） |

| `js/ui/` | 一覧・詳細・絞り込み・設定・シート・タブバー |

| `sw.js` | Service Worker（アプリ本体のオフラインキャッシュ） |
| `tests/` | `npm test`（品番判定・ファイル構成の検査） |
| `server/` | 旧版（Mac 上で Node のサーバーとして動かす版） |

## 仕組み

- 各サイトの WordPress REST API（`/wp-json/wp/v2/posts`）をブラウザから直接呼ぶ（各サイトが CORS を許可しているため可能）
- 通信量を抑えるため、一覧用にはタイトル・日付・タグ・サムネイルだけを取り、再生プレイヤーの URL は詳細を開いたときに取る
- 重複のまとめ方
  1. タイトルかタグにある品番（例: `MR-KR2387`, `GT-2720`）が同じものは 1 本にまとめる
  2. 品番がないものは、記号と空白を除いたタイトルが同じなら 1 本にまとめる

## 開発

```bash
npm run serve
```

```bash
npm test
```

`http://localhost:8790/?dev` で確認できる（`?dev` を付けると各サイト 1 ページ目だけ取得する）。`main` に push すると GitHub Pages に反映される（1〜2 分）。
